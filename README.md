## Солнечные часы (тень)

Многоязычное консольное приложение для расчёта длины и направления тени, отбрасываемой вертикальным гномоном (шестом) в заданное время и место на Земле.  
Позволяет визуализировать положение Солнца и тени, что полезно для проектирования солнечных часов, садового дизайна или образовательных целей.

## Особенности
- Расчёт высоты Солнца над горизонтом и азимута на основе даты, времени и географических координат.
- Вычисление длины тени от вертикального гномона заданной высоты.
- Определение направления тени (азимут).
- Цветная визуализация тени в консоли (ASCII-графика) — вид сверху.
- Поддержка произвольной даты, времени, часового пояса (по умолчанию — текущее время).
- Автоматическое определение географических координат по IP (опционально).
- Экспорт результатов в JSON и CSV.
- Пакетный режим: расчёт тени на протяжении дня.
- Цветной вывод в терминале (где поддерживается).

## Установка и запуск
Для каждого языка требуются соответствующие инструменты и зависимости.

### Запуск на разных языках

1. **Python**  
   Установка: `pip install colorama requests` (requests для геолокации по IP).  
   Запуск: `python sundial.py --lat 55.75 --lon 37.62 --height 1.0 --time "12:00"`

2. **JavaScript (Node.js)**  
   Установка: `npm install commander chalk`  
   Запуск: `node sundial.js --lat 55.75 --lon 37.62 --height 1.0 --time "12:00"`

3. **Go**  
   Запуск: `go run sundial.go --lat 55.75 --lon 37.62 --height 1.0 --time "12:00"`

4. **Rust**  
   Сборка: `cargo build --release`  
   Запуск: `cargo run -- --lat 55.75 --lon 37.62 --height 1.0 --time "12:00"`

5. **Java**  
   Сборка: `javac -cp gson.jar Sundial.java`  
   Запуск: `java -cp .;gson.jar Sundial --lat 55.75 --lon 37.62 --height 1.0`

6. **C# (.NET Core)**  
   Установка: `dotnet add package Newtonsoft.Json`  
   Запуск: `dotnet run -- --lat 55.75 --lon 37.62 --height 1.0`

7. **C++ (Linux)**  
   Сборка: `g++ -std=c++11 -o sundial sundial.cpp -ljsoncpp -lm`  
   Запуск: `./sundial --lat 55.75 --lon 37.62 --height 1.0`

8. **Kotlin (JVM)**  
   Сборка: `kotlinc -cp gson.jar Sundial.kt`  
   Запуск: `kotlin -cp .;gson.jar SundialKt --lat 55.75 --lon 37.62 --height 1.0`

## Использование

Общие аргументы командной строки:

- `--lat <градусы>` – широта (северная положительная).
- `--lon <градусы>` – долгота (восточная положительная).
- `--date <YYYY-MM-DD>` – дата (по умолчанию сегодня).
- `--time <HH:MM[:SS]>` – местное время (по умолчанию текущее).
- `--height <метры>` – высота гномона (по умолчанию 1.0 м).
- `--tz <часы>` – часовой пояс от UTC (по умолчанию определяется автоматически).
- `--shadow` – показать ASCII-визуализацию тени (вид сверху).
- `--day` – рассчитать тень на весь день с шагом 1 час (экспорт в CSV/JSON).
- `--json <файл>` – экспорт результата в JSON.
- `--csv <файл>` – экспорт в CSV.
- `--help` – справка.
